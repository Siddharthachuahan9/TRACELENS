Capabilities

Everything you need to debug APIs.
Nothing you don't.

Timing Waterfall

Visual breakdown of every request phase — DNS, TCP, SSL, server wait, download. Instantly see where time is spent.

JWT Token Inspector

Automatically decodes Bearer tokens. Live countdown to expiry. Subject, email, role, and algorithm — all at a glance.

Incident Reports

One-click Jira-ready reports with environment, endpoint, auth status, trace ID, and automated diagnosis.

Replay & Export

Copy as cURL or fetch(). Export Postman collections. Download HAR files. Share .tracelens snapshots with your team.

GraphQL Aware

Detects GraphQL requests automatically. Extracts operation names. Labels mutations and subscriptions distinctly.

Cascade Detection

Alerts when 3+ consecutive slow requests fire — indicating downstream service degradation before it becomes an outage.

Request Diff

Compare fast vs slow requests to the same endpoint. See what changed in the response — field by field.

Diagnosis Engine

Rule-based analysis that reads status codes, timing phases, and auth state — then tells you what went wrong in plain English.

Architecture

How TraceLens works.

01

Capture

TraceLens hooks into chrome.devtools.network to observe completed HTTP requests. Nothing is modified. Nothing is blocked. Pure observation.

02

Enrich

Each request is augmented in real time — JWT tokens are decoded, retry patterns detected, GraphQL operations named, and requests grouped into user-action bursts.

03

Analyze

The diagnosis engine evaluates each request against dozens of rules — checking status codes, timing distribution, auth state, payload size, and connection phases.

04

Present

Results render in a purpose-built interface with a real-time timeline, timing waterfall, token inspector, and request diff — all built with vanilla JS for zero overhead.

05

Export

Share findings as cURL commands, fetch snippets, Postman collections, HAR files, .tracelens snapshots, or Jira-ready incident reports — one click each.

Privacy & Security

Your data never leaves your browser.

TraceLens is architecturally incapable of exfiltrating data. It requests only the storage permission — for saving your settings. There are no content scripts, no remote API calls, no analytics, no telemetry.

Read-only

Cannot modify network traffic. No webRequest permission. No declarativeNetRequest.

No injection

No content scripts. No page modification. No scripting permission.

No phone home

Zero external network calls. No analytics. No telemetry. No tracking.

Memory only

Captured data lives in browser memory. Close the tab — it's gone. Nothing persisted to disk.

Open source

Every line of code is on GitHub. Audit it yourself. No obfuscation. No minification.

Minimal permissions

Only storage — used exclusively for saving your settings preferences.
