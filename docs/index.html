01 Capabilities

Everything you need
to debug APIs.

Timing Waterfall DNS, TCP, SSL, server wait, and download — visualized per request. Cached phases labeled. Bottleneck identified at a glance, in milliseconds.
JWT Inspector Decodes Bearer tokens automatically. Live countdown to expiry. Subject, scope, issuer, algorithm — all visible without leaving DevTools.
AI Assistant Ask Claude or GPT to explain errors, draft reports, or analyze timing. Auth tokens, cookies, and passwords are always stripped before sending.
Diagnosis Engine Rule-based analysis on status codes, timing phases, and auth state. Tells you what went wrong in plain English — not just the status code.
Cascade Detection Alerts when 3+ consecutive slow requests fire — early signal of downstream degradation before it becomes a full outage.
Request Diff Compare fast vs slow requests to the same endpoint. See what changed in the response, field by field, without writing a script.
Replay & Export Copy as cURL, fetch(), or Python. Export Postman collections, HAR files, .tracelens snapshots, or Jira-ready incident reports. One click each.
Performance Baseline Snapshot endpoint averages and get alerted when requests regress beyond a configurable threshold — catch slowdowns the moment they appear.

02 Privacy & Security

Your data never
leaves your browser.

TraceLens requests only the storage permission — for saving your settings. No content scripts. No remote API calls. No analytics. No telemetry. Architecturally incapable of exfiltrating data.

03 Get Started

Running in 60 seconds.

1
Clone the repo git clone https://github.com/Siddharthachuahan9/TRACELENS
2
Open Chrome extensions chrome://extensions → Enable Developer mode
3
Load unpacked

Click "Load unpacked" and select the tracelens/ folder.

4
Open DevTools

Press F12 on any page, then click the TraceLens tab.

No build step. No npm. No configuration. Chrome Web Store listing coming soon.
